# Web API contract

The website (`web/`) talks to the backend's web service
(`src/jobpilot/web/`) over this HTTP API. Both sides are written against
this document, so it is the single source of truth for paths, payloads,
and stream events. All paths are prefixed `/api/v1`. All bodies are JSON
unless noted. Timestamps are ISO-8601 UTC strings. IDs are UUID strings.

Authentication is a bearer token: `Authorization: Bearer <access_token>`
on every route except `/auth/*` and `/healthz`.

## Auth (email one-time code)

| Method | Path | Body | Response |
|---|---|---|---|
| POST | `/auth/request-code` | `{ "email": string }` | `202 { "sent": true }` |
| POST | `/auth/verify-code` | `{ "email": string, "code": string }` | `200 { "access_token": string, "expires_at": string, "user": User }` |
| GET | `/me` | - | `200 User` |

```ts
type User = { id: string; email: string; full_name: string | null;
  seniority_band: SeniorityBand | null; preferred_location_tiers: LocationTier[];
  has_resume: boolean; created_at: string }
```

## Conversations (chat)

| Method | Path | Body | Response |
|---|---|---|---|
| GET | `/conversations` | - | `200 ConversationSummary[]` (newest first) |
| POST | `/conversations` | `{}` | `201 ConversationSummary` |
| GET | `/conversations/{id}/messages` | - | `200 ChatMessage[]` (oldest first) |
| POST | `/conversations/{id}/messages` | `{ "body": string, "client_message_id": string }` | `202 { "message_id": string, "turn_id": string }` |
| GET | `/conversations/{id}/turns/{turn_id}/stream` | - | `text/event-stream` (below) |

`client_message_id` is generated by the browser (UUID v4). Posting the same
one twice returns the original `message_id`/`turn_id` instead of creating a
second turn, so a double-click or a network retry never produces two replies.

```ts
type ConversationSummary = { id: string; title: string; last_message_preview: string | null;
  updated_at: string }
type ChatMessage = { id: string; role: "user" | "assistant"; body: string;
  job_cards: JobCard[]; tailoring_id: string | null; created_at: string }
```

### Stream events (Server-Sent Events)

Each event has an `event:` name and a JSON `data:` line.

| event | data | meaning |
|---|---|---|
| `status` | `{ "phase": "thinking" \| "calling_tool" \| "writing" }` | what the agent is doing right now |
| `tool_call` | `{ "call_id": string, "name": ToolName, "label": string }` | agent started a tool; `label` is human text e.g. "Searching remote backend roles" |
| `tool_result` | `{ "call_id": string, "name": ToolName, "ok": boolean, "summary": string }` | tool finished; `summary` e.g. "Found 6 matching roles" |
| `token` | `{ "text": string }` | next chunk of the reply text |
| `job_cards` | `{ "cards": JobCard[] }` | structured job results to render under the reply |
| `tailoring_started` | `{ "tailoring_id": string, "job_id": string }` | agent kicked off a resume tailoring from chat |
| `done` | `{ "message_id": string }` | reply persisted; stream closes |
| `error` | `{ "code": string, "message": string, "retryable": boolean }` | turn failed; stream closes |

`ToolName = "search_jobs" | "recall_memory" | "fetch_resume" | "get_job_details" | "tailor_resume"`

## Jobs

| Method | Path | Body | Response |
|---|---|---|---|
| GET | `/jobs/{job_id}` | - | `200 JobDetail` |
| POST | `/jobs/{job_id}/save` | - | `204` |
| DELETE | `/jobs/{job_id}/save` | - | `204` |
| GET | `/saved-jobs` | - | `200 JobCard[]` |

```ts
type JobCard = { job_id: string; title: string; company: string; location_text: string | null;
  location_tier: LocationTier; seniority_band: SeniorityBand; role_category: RoleCategory;
  skills: string[]; description_preview: string; compensation_text: string | null;
  apply_url: string; match_score: number; match_reasons: string[]; posted_at: string | null;
  is_saved: boolean }
type JobDetail = JobCard & { description: string; employment_type: EmploymentType;
  min_years_experience: number }
```

## Resumes

| Method | Path | Body | Response |
|---|---|---|---|
| POST | `/resumes` | `multipart/form-data`, field `file` (PDF or DOCX, max 5 MB) | `202 { "resume_id": string, "status": "parsing" }` |
| GET | `/resumes` | - | `200 ResumeSummary[]` |
| GET | `/resumes/{id}` | - | `200 Resume` |
| POST | `/resumes/{id}/primary` | - | `204` (makes this the resume the agent uses) |

```ts
type ResumeStatus = "parsing" | "ready" | "failed"
type ResumeSummary = { id: string; file_name: string; status: ResumeStatus; is_primary: boolean;
  uploaded_at: string }
type Resume = ResumeSummary & { failure_reason: string | null; sections: ResumeSections | null }
type ResumeSections = {
  contact: { name: string; email: string | null; phone: string | null; location: string | null;
             links: string[] };
  summary: string | null;
  experience: { id: string; company: string; title: string; start: string; end: string | null;
                bullets: { id: string; text: string }[] }[];
  education: { id: string; institution: string; degree: string; start: string | null;
               end: string | null; score: string | null }[];
  projects: { id: string; name: string; bullets: { id: string; text: string }[];
              tech: string[] }[];
  skills: string[] }
```

## Tailoring

| Method | Path | Body | Response |
|---|---|---|---|
| POST | `/tailorings` | `{ "resume_id": string, "job_id": string }` or `{ "resume_id": string, "job_description_text": string }` | `202 { "tailoring_id": string, "status": "running" }` |
| GET | `/tailorings/{id}` | - | `200 Tailoring` (poll until status is not `running`) |
| POST | `/tailorings/{id}/decisions` | `{ "accepted": string[], "rejected": string[] }` (suggestion ids) | `200 Tailoring` |
| GET | `/tailorings/{id}/export?format=pdf\|docx` | - | file download |

```ts
type Tailoring = { id: string; resume_id: string; job_id: string | null; job_title: string;
  company: string | null; status: "running" | "ready" | "failed";
  score_before: number; score_after: number;           // 0-100
  keywords: { term: string; importance: "required" | "preferred"; found_in_resume: boolean;
              covered_after: boolean }[];
  suggestions: Suggestion[]; created_at: string }
type Suggestion = { id: string; kind: "rewrite_bullet" | "rewrite_summary" | "add_skill" | "reorder_section";
  target_id: string | null;   // bullet id / section name it applies to
  section: "summary" | "experience" | "projects" | "skills";
  original: string | null; proposed: string; reason: string; keywords_added: string[];
  decision: "pending" | "accepted" | "rejected" }
```

## Errors

Any non-2xx response has the body `{ "error": { "code": string, "message": string } }`.
Codes used: `unauthorized`, `not_found`, `validation_failed`, `rate_limited`,
`resume_not_ready`, `file_too_large`, `unsupported_file_type`, `internal`.
